# 挺店 WANGPU

商圈優質名店「營收分潤融資（RBF）＋ RWA」平台 — 前端原型。

## 這個平台在做什麼

現在許多在地的優質店家（咖啡廳、選品店、麵店、披薩店……）想擴張、裝修、
添購設備，卻很難從銀行拿到貸款，也不想為了一筆資金稀釋股權、找股東。
**挺店**提供另一條路：讓商家把「未來一段時間的營收」拿出來，換取小額
資金；讓投資人用小額資金換取這筆「營收分潤權」，按月分到店家實際的
營收分潤。

- **不是借貸**——沒有固定利息、沒有到期一次還清的壓力，商家依實際月
  營收提撥分潤，淡旺季自動反映在還款金額上。
- **不是股權**——商家不用稀釋股份、不用找董事會，資金到位速度更快。
- **投資人不只是投資人，更是消費者**——投資某家店之後，會拿到該店的
  投資人專屬到店優惠／消費金折抵，把投資報酬導回實際消費，形成「投資
  ×消費」的雙向循環。
- **AI Agent 全程監控**——風險評估、營收異常偵測、促購提醒都由 Agent
  持續運作，而不是核准當下算一次分數就結束。
- **資金第三方信託保管**，分潤結算全程可追蹤，POS／電子支付／銀行金流
  ／電子發票交叉驗證，降低造假與異常風險。

## 兩種角色，兩個獨立網站

這個 repo 裡有**兩個各自獨立的前端專案**，分別對應平台的兩種使用者：

| 網站 | 是誰在用 | 可以做什麼 |
|---|---|---|
| 🔗 **[投資人平台](https://funding-amber.vercel.app/)** | 投資人 | 瀏覽商家與 AI 風險評分、投資分潤權、追蹤持股與分潤、意向轉讓看板（提前變現）、領取投資人專屬優惠券 |
| 🔗 **[商家平台](https://funding-fefg.vercel.app/)** | 商家 | 線上申請融資（核實資料 → 核貸結果 → 自訂資金用途）、查看營收與 AI 評估、追蹤撥款與還款進度 |

兩個網站都已經上線，**點連結就能看，不需要安裝任何東西、不需要下載程式碼**。
內容仍在持續更新，兩邊都接了自動部署，每次更新程式碼都會自動重新建置。

## 這是什麼程度的原型

這兩個網站都是**純前端展示用途，沒有真實後端**：所有商家、營收數據、
融資申請、核貸結果都是模擬（mock）資料，操作只會寫入你瀏覽器的
`localStorage`，不會有任何真實交易、真實撥款或對外連線，也不會在兩個
網站之間互相同步資料。目的是完整呈現產品的操作流程與介面設計，用於
競賽／提案展示。

## 風險與合規揭露

本專案為概念性產品原型（Prototype），所有商家、營收數據與募資進度均為
示範用途，非真實存在之商家或交易。「營收分潤權」並非存款、保證收益商品，
投資人可能面臨本金虧損風險；歷史或預估報酬不代表未來實際表現。實際商品
之法律性質、契約架構與募集方式須以受監管金融機構公告之正式條款為準。
